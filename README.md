# SongSwipe（刷歌）

像刷短视频一样刷歌：打开就播，一首歌一屏，上滑换一首，双击红心。
玩法参照 QQ 音乐、汽水音乐的竖滑听歌流，调研见 [docs/01-刷歌玩法调研.md](docs/01-刷歌玩法调研.md)。

界面是英文版，面向菲律宾和全球用户。曲库先查 iTunes 菲律宾区，再查美区。App 名称定义在 `lib/app_info.dart`，改名只改这一处。

## 功能

| 交互 | 行为 |
|---|---|
| 上滑 / 下滑 | 下一首 / 回到上一首（回听会被记为加分） |
| 单击 | 暂停 / 继续 |
| 双击 | 红心（只加不减）+ 爆心动画 + 震动 |
| 右侧栏 | 点赞、评论、收藏、分享（复制文案）、不感兴趣（屏蔽歌手） |
| 底部 | 推荐理由、歌名歌手、可拖动进度条 |
| 顶部 | 搜索、口味画像（可重置）、我的（收藏、点赞、偏好、退出登录） |

- **会员**：用户名加密码注册登录。注册后选听歌偏好，包括语言、风格、歌手和网红热歌，第一批推荐就按偏好来。偏好随时可在「我的」里修改。
- **搜索**：搜歌名或歌手，点结果立即播放，播完接着刷推荐。搜过的词会让推荐往这个方向偏，越近的搜索权重越高。
- **点赞和收藏分开**：点赞是红心，双击也是点赞。收藏是星标，收进「我的」方便回听。两者都会影响推荐，收藏的权重更高。
- **评论**：带用户名和时间，自己的评论长按可以删除。
- **热歌**：开启后约四分之一的推荐来自 Apple Music 菲律宾区和美区的热门榜，拉不到时改搜短视频上走红的歌手。

- **原生播放队列**：刷歌流里的歌都排在系统原生播放器的队列里。播完一首由系统自己接下一首，不经过 App 代码，锁屏、熄屏时照样无缝连播。加载失败的歌会被自动跳过。
- **不断粮**：每次搜歌没用上的结果会留作备用。网络出错或搜不到新歌时，直接从备用里出歌。
- **锁屏和通知栏**：锁屏显示封面、歌名和进度，可以播放暂停、上一首、下一首、拖动进度。安卓通知栏额外有红心按钮。耳机线控和蓝牙按键同样可用。
- **零等待**：下一首由原生播放器提前缓冲。
- **隐式反馈推荐**：秒划、半途划走、听完、回听、红心、不感兴趣分别加减分，按「歌手全额、风格半额」累计。
- **按账号隔离**：点赞、收藏、口味画像和搜索历史都按账号分开存，同一台手机换账号互不影响。
- **防信息茧房**：固定 20% 流量用于探索，同一批最多 2 首同歌手，每张卡片都写明推荐理由。
- **歌词**：来自 LRCLIB，跟着播放逐行滚动。试听片段的起点接口不提供，先假定从副歌开始；对不上时点一下正在唱的那一行就能校准，校准结果按歌曲记住。

## 直接试用（安卓）

不用装任何开发工具。打开仓库的 Releases 页面，找最新的「SongSwipe 试用版」，用手机浏览器下载 app-release.apk 并安装。首次安装需要允许「安装未知来源应用」。

安装包由 GitHub Actions 自动构建：每次推送代码都会先跑分析和测试，全部通过才打包发布。

## 运行

需要 Flutter 3.50 或更新版本。

```bash
flutter pub get
```

```bash
flutter run
```

真机或模拟器会直接请求 iTunes 曲库，需要联网。没有网络时可以用离线演示模式预览界面，歌曲是占位数据，播放进度由计时器模拟：

```bash
flutter run -d chrome --dart-define=SHUAGE_DEMO=true
```

## 平台配置说明

- **安卓**：入口 Activity 继承自 audio_service 的 Activity，锁屏后 Flutter 引擎由播放服务托管，Dart 代码继续运行。清单里声明了媒体播放类前台服务和媒体按键接收器。
- **iOS**：Info.plist 开启了后台音频。

## 测试

```bash
flutter analyze
```

```bash

```

```
  app.dart                     入口切换：登录页、首次偏好设置、刷歌流
  account/                     账号接口与本机实现、密码哈希、听歌偏好
  social/comment.dart          评论接口与本机实现
  models/track.dart            歌曲模型，含 iTunes 字段映射
  data/
    track_source.dart          音源接口：换曲库只换这里
    itunes_source.dart         iTunes Search API，30 秒试听
    lyrics_source.dart         LRCLIB 歌词
    trending_source.dart       热歌榜：Apple Music 菲律宾区和美区最多播放
    library_store.dart         按账号存的个人数据：点赞、收藏、口味、搜索历史
  recommend/
    taste_profile.dart         信号定义与口味打分
    recommender.dart           80% 投其所好 + 20% 探索，接入偏好、搜索和热歌
    preference_options.dart    偏好选项，以及偏好到搜索词的映射
  audio/
    audio_engine.dart          播放队列接口，以及区分「自动换歌」和「跳转回声」的判定
    just_audio_engine.dart     just_audio 原生队列实现
    now_playing.dart           系统媒体会话接口：推送状态、接收锁屏指令
    system_media_session.dart  audio_service 实现：锁屏、通知栏、线控
  feed/feed_controller.dart    刷歌流状态机：翻页、计分、续播、拉下一批
  lyrics/                      LRC 解析、副歌估算
  ui/                          主页、单屏卡片、歌词、红心动画、各类弹层
  demo/demo_mode.dart          离线演示模式
```

## 已知限制

- **只有 30 秒试听**。iTunes 不提供完整歌曲，接入正版全曲需要实现新的音源，并给歌曲填入高潮起播点。
- **试听片段的歌词起点是估算的**。iTunes 不告诉片段在原曲中的位置，第一次刷到某首歌时可能偏几秒到十几秒，需要点一下校准。
- **iOS 锁屏没有红心按钮**。audio_service 在 iOS 上禁用了「喜欢」指令，红心只在安卓通知栏提供。
- **长时间断网会停**。试听音频是在线播放的，备用歌也需要联网才能播。断网时 iOS 可能挂起 App，恢复网络后需要回到 App 继续。离线缓存还没做。
- **账号和评论只在本机**。目前没有服务器：换手机账号就没了，评论也只有同一台手机上的账号能看到。账号和评论都做成了接口，接服务器时换实现即可。
- **点赞没有总数**。没有服务器就统计不了所有人的点赞数。
- **热歌是近似值**。TikTok 没有公开的热歌接口，用的是 Apple Music 的热门榜。
